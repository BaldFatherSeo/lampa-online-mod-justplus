> 🧪 **Статус: beta.** Ранняя версия моста уже дала рабочее переключение серий в Just+ на Android. Изменения v2.0, включая кэш и новое окно, проверены синтаксически и в имитационных сценариях, но пока не подтверждены на реальном телефоне. Пожалуйста, сообщайте о проблемах через [Issues](https://github.com/BaldFatherSeo/lampa-online-mod-justplus/issues).

## Быстрая установка

**Основной адрес расширения через jsDelivr:**

```text
https://cdn.jsdelivr.net/gh/BaldFatherSeo/lampa-online-mod-justplus@main/online_mod_justplus_bridge.js
```

**Адрес конкретно v2.0.0 (не зависит от кэша обновлений ветки main):**

```text
https://cdn.jsdelivr.net/gh/BaldFatherSeo/lampa-online-mod-justplus@627d78d/online_mod_justplus_bridge.js
```

**Резервная ссылка GitHub Raw:**

```text
https://raw.githubusercontent.com/BaldFatherSeo/lampa-online-mod-justplus/main/online_mod_justplus_bridge.js
```

1. Установите **Lampa Android**, **Online MOD** и **Just+ Player**. Убедитесь, что просмотр одной серии через Online MOD уже работает.
2. Откройте **Lampa → Настройки → Расширения → Добавить плагин** и вставьте одну JS-ссылку выше.
3. Полностью закройте и заново откройте Lampa, чтобы старые JS-патчи не остались в памяти.
4. Откройте **Настройки → Online MOD + Just+** и активируйте **«Переключение серий в Just+»**.
5. В Lampa выберите **Android / внешний плеер**, затем запускайте сериалы из Online MOD через Just+ Player.

**Termux не нужен.** VPN также не нужен для работы самого плагина, если ваш интернет открывает адрес CDN; доступность самих источников Online MOD зависит от сети.

Если после обновления виден старый интерфейс, удалите предыдущую ссылку из расширений, используйте адрес конкретной версии и полностью перезапустите Lampa. **Не держите две версии моста одновременно.**

## Что добавлено в v2.0

- **Переключение эпизодов:** готовый набор URL передаётся через механизм запуска внешнего Android-плеера Lampa.
- **Накопительный кэш:** известные ссылки сохраняются локально по комбинации «сериал / балансер / сезон / озвучка / серия». Уже сохранённые серии не запрашиваются повторно.
- **Поддержка больших списков:** данные распределены по блокам по **100 эпизодов**. Прогресс сохраняется каждые 10 найденных ссылок и при штатной остановке.
- **Центральное окно подготовки:** счётчик «готово / всего», процент, попадания в кэш и недоступные серии.
- **Без общего тайм-аута:** получение ссылок идёт до завершения либо ручной остановки. При зависшем источнике окно не исчезает само.
- **«Запустить без сбора»:** кнопка с подтверждением останавливает процесс и открывает **только выбранную серию**. Уже найденные ссылки остаются в кэше.
- **Очистка кэша:** **Настройки → Online MOD + Just+ → Удалить сохранённые списки серий**. Сначала появится подтверждение; история просмотров и другие расширения не затрагиваются.

## Как устроен кэш

Online MOD часто хранит URL остальных эпизодов в виде функций и запрашивает настоящие ссылки лишь по мере выбора серии. Just+ Player же нужен готовый набор ссылок.

Плагин берёт **метаданные сериала, выбранный источник, сезон, озвучку и порядок эпизодов**, сохраняет **уже разрешённые URL с метаданными воспроизведения** в хранилище Lampa на **текущем устройстве** и при следующем просмотре сначала использует сохранённые эпизоды. Из них формируется временный плейлист для передачи Just+.

Для 10 000 серий не создаётся одна гигантская запись: кэш разбит на 100-эпизодные блоки. Тем не менее **запрос тысяч ещё не найденных URL может быть долгим и потреблять память**. Кнопка просмотра без полного сбора предназначена именно для таких случаев.

**Важно:** некоторые балансеры выдают временные, подписанные URL. Если сохранённые эпизоды перестали запускаться, удалите кэш через настройки — адреса будут запрошены заново. Плагин не может гарантировать бессрочную действительность сторонних ссылок.

## Частые вопросы

**Не отображаются кнопки серий?** Проверьте версию Android-приложения Lampa, выбор внешнего плеера Just+, включение моста и выбранный источник Online MOD. Некоторые источники не предоставляют список эпизодов.

**Не загружается расширение с GitHub Raw?** Используйте jsDelivr-ссылку. Если она тоже недоступна, проверьте доступ в браузере телефона.

**Online MOD перестаёт работать с VPN?** Это отдельно от моста. Отключите VPN для Lampa, если именно так источники работают у вас.

**Прогресс остановился на одной серии?** В этой версии нет принудительного тайм-аута. Выберите **«Запустить без сбора»**, подтвердите действие; ранее найденное сохранится. Следующий запуск продолжит сбор недостающих ссылок.

**Как освободить место?** В **Настройки → Online MOD + Just+** нажмите **«Удалить сохранённые списки серий»**.

**Что насчёт воспроизведения?** Мост не изменяет сами видеопотоки, не расшифровывает DRM, не содержит медиаконтента и не гарантирует работу с конкретным провайдером.

## Для разработчиков

- Основной файл: [`online_mod_justplus_bridge.js`](./online_mod_justplus_bridge.js).
- Никаких обязательных npm-зависимостей и сборки.
- Включение: `Lampa.Storage.field('online_mod_justplus_bridge_enabled')`.
- Данные кэша: ключи с префиксом `online_mod_justplus_cache_v2_` и индекс `online_mod_justplus_cache_index_v2`.
- Настройки: `Lampa.SettingsApi.addComponent` и `addParam`.
- Работа с внешним проигрывателем: `Lampa.Player.play` / `Lampa.Player.playlist`.

Пожалуйста, создавайте [Issues](https://github.com/BaldFatherSeo/lampa-online-mod-justplus/issues) с версиями Lampa и Just+, названием балансера и пошаговым описанием проблемы. **Не публикуйте токены, cookies, приватные URL и персональные данные.**
